# Página Pessoal 👤

Meu portfólio e página pessoal onde apresento minha trajetória, projetos e experiências como desenvolvedor. Esta página funciona como um cartão de visita digital, permitindo que visitantes conheçam mais sobre mim e meus trabalhos.

## 🎯 Objetivo
Criar um portfólio profissional que showcase minhas habilidades, projetos e experiência de forma elegante e organizada.

## 🚀 Como Acessar

### Online (Recomendado)
Acesse meu portfólio através do link do deploy:
👉 [Página Pessoal - Vercel](https://pagina-pessoal-nova.vercel.app)

### Localmente
1. Clone o repositório:
   ```bash
   git clone https://github.com/Danillo-FG/Pagina-pessoal.git
   cd Pagina-pessoal
   ```

2. Abra o arquivo `index.html` no seu navegador

## 📋 Seções da Página
- **Início (Home)** - Apresentação inicial
- **Sobre (About)** - Informações sobre mim
- **Projetos** - Portfólio com meus trabalhos
- **Contato** - Formas de me contatar
